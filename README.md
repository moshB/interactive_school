# מרחב מתמטי

סביבת למידה אינטראקטיבית בעברית לתלמידי תיכון. שלב הכלים המתמטיים כולל מקלדת מתמטית וירטואלית ומחשבון גרפי אינטראקטיבי.

## דרישות

- Node.js 20.19+ או 22.12+
- npm

## הפעלה מקומית

1. התקינו את התלויות באמצעות `npm install`.
2. הפעילו את שרת הפיתוח באמצעות `npm run dev`.
3. לבדיקת גרסת הפקה, הריצו `npm run build`.

## מחשבון גרפי

הקלידו ביטויים כגון `x^2 - 3*x + 1`, `sqrt(x)`, `sin(x)` או `1/x`. המחשבון מציג כמה גרפים בצבעים שונים, שבר בתצוגה אנכית, חזקות ושורשים בסימון מתמטי, חיתוכים משוערים עם הצירים ונקודות קיצון מספריות. אפשר לגרור את מערכת הצירים, לשנות את קנה המידה ולעקוב אחר ערכי הגרפים.

## תוכנית לימודים לכיתה י׳

מסע הנגזרות כולל הסבר מושגי על קצב שינוי ושיפוע המשיק, כללי נגזרת ראשונים, ושישה תרגילים בדרגת קושי עולה. התלמידים מזינים תשובות במקלדת אלגברה, מקבלים משוב, צוברים נקודות ורצף הצלחות. בדיקת שקילות התשובות מיועדת כרגע לדוגמאות הפולינומיות שבשיעור ואינה מנוע הוכחה סמלי כללי.

## מבנה מרכזי

- `src/app/` — מעטפת היישום והרכבת ממשקי המשתמש.
- `src/modules/math/domain/` — פענוח ביטויים וניתוח מספרי של נקודות קיצון.
- `src/modules/math/graphing/` — מחשבון גרפי ותצוגה מתמטית של ביטויים.
- `src/modules/math/input/` — מקלדת מתמטית מעוצבת והכנסת סימנים לשורה הפעילה.
- `src/modules/student/` — סביבת התלמיד ותהליכי הלמידה.
- `src/modules/student/derivatives/` — שיעור ותרגול מדורג בנושא נגזרות לכיתה י׳.
- `src/modules/teacher/` — שלד ראשוני לממשק המורה.
- `.github/skills/` — מפרטי הארכיטקטורה והמודולים.
- `.github/skills/grade10-derivatives.md` — מפרט תוכן, זרימת למידה ובדיקת תשובות לנגזרות.
- `docs/ARCHITECTURE.md` — גבולות המודולים ותוכנית ההעברה ההדרגתית.

ממשק המורה בשלב זה הוא שלד תצוגה בלבד; אין עדיין התחברות, קבוצות, שמירת מידע או חיבור לשרת. נקודות החיתוך והקיצון מחושבות בקירוב מספרי ואינן תחליף להוכחה אלגברית.
